OMB Charge

by Semilir Semarang

Panduan singkat buat kamu yang mau ngecas motor listrik di titik charge OMB.

Admin OMB Charge
0896-7205-6155
1

Hubungi admin

Kirim pesan ke admin dengan format berikut, sebutkan ID OMB atau nama kamu.

Format pesan MAU NGECAS — [ID OMB / Nama]
2

Listrik dinyalakan

Admin menyalakan aliran listrik dan mengirim angka kWh meter awal. Catat angka ini, jadi patokan hitungan tagihan.

kWh meter awaldari admin
3

Colok & charge motor

Sambungkan motor ke titik charge, tunggu sampai baterai terisi sesuai kebutuhan kamu.

4

Selesai charge, hubungi admin lagi

Begitu pengecasan selesai, langsung kabari admin — jangan ditunda.

5

Admin catat kWh meter akhir

Selisih antara kWh meter awal dan akhir jadi dasar hitungan biaya jasa charge kamu.

6

Terima nota & bayar

Admin mengirim nota pembayaran beserta QRIS. Scan, bayar, selesai.

Penting: selalu hubungi admin begitu selesai charge

Kalau kamu enggak menghubungi admin setelah selesai, listrik tetap menyala dan tagihan kWh terus berjalan. Kalau pengguna berikutnya sempat memakai listrik yang masih nyala itu, tagihannya bisa ikut dibebankan ke kamu sebagai pengguna sebelumnya.
